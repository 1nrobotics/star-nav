# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussion focused on the work. Harassment and personal attacks are not
tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour to the maintainers at dev@1nrobotics.com. Reports
are handled confidentially.
